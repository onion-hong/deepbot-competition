# Git 纳入范围与排除审查

精确纳入路径逐行见 BASELINE_FILES.txt（含清单自身），只允许按该清单 `git add --pathspec-from-file=competition/docs/BASELINE_FILES.txt`；本轮不使用 `git add .`，不提交历史目录，不推送远端。后续新增文件先由所属模块审查，再显式纳入。

本轮扫描了纳入文本中的私钥头、常见token、密码赋值、个人用户目录、邮箱、SSH密钥路径及IPv4；并检查扩展名/1MiB大小阈值。命中经审阅仅为 `.gitignore` 两条密钥排除规则、历史隔离传输测试中的4处回环地址；不是真实设备IP或秘密。未发现纳入内容含私钥/令牌/密码字面量、个人邮箱/用户目录、大文件或模型。自动规则不保证检出一切秘密；二进制和D盘报名材料未逐字节扫描。

不纳入原始日志/交接的理由包括个人本机目录、历史连接IP、临时SSH密钥路径与设备指纹。没有复制密钥文件、没有输出其内容。Git提交身份使用用户已有配置（其中邮箱属于个人元数据），本轮未改变用户身份设置，也未推送。
