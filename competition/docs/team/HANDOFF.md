## 自检与命令核对

本轮仅运行既有 CLI 的 `--help`：data_tools 主入口及 start/stop/event/export/inspect；perception.replay；mission.replay 及 demo；verify_data_perception.py。十个帮助命令均正常返回，文档参数与这些入口一致。未运行录制、导出、感知计算、任务演示、90 项测试、安装依赖或实际打包。

三份 Markdown 的本地相对链接已逐个解析，目标均存在且留在仓库内。公开内容扫描未发现本机盘符路径、个人邮箱、历史连接 IPv4 地址或原开发者本机用户名。数据目录、解释器和现场连接地址均用变量，不包含队友账号或凭据。扫描是明确模式的自动检查与人工阅读，不是对整个仓库内容作出的隐私审计结论。

打包片段只用 Python 标准库，已按 Python 3.8 语法解析，采用新目录/新 ZIP/独占写入，不删除旧数据，文件列表用相对路径和 SHA-256。没有对真实数据执行该片段，没有宣称实测大数据包开包成功。接收者的归档哈希、逐文件与 inspect 回读步骤已写入指南。

精确帮助输出、各文件链接/扫描结果及本轮读取的实现哈希见 VALIDATION.json。它只记录仓库相对路径和解释器版本，不保存本机解释器绝对路径。
